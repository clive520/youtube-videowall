# YouTube 電視牆 4 分割播放清單 (4-Grid YouTube Video Wall)

這是一個專為電視牆、展示螢幕或多工監控設計的 4 格分割 YouTube 播放清單網頁。

## 功能特色
- **四等份均分（2x2 電視牆配置）**：自動滿版填滿螢幕（100vw × 100vh），左右上下各 50%，無滾動條或多餘邊框。
- **自動播放與預設靜音**：符合現代瀏覽器安全自動播放規範，頁面載入即自動播放並關閉聲音。
- **播放清單循環支援**：支援各播放清單連續循環播放。
- **懸浮智慧控制列**：
  - 閒置時自動隱藏，滑鼠移動或觸控時自動顯現。
  - 支援「全部播放」、「全部暫停」、「一鍵切換靜音/開音量」、「全螢幕模式（F11 效果）」。
- **YouTube IFrame API 深度整合**：確保影片狀態同步與播放指令準確送達。
